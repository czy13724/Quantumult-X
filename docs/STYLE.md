# 脚本头部规范

本文档说明 `scripts/` 目录脚本的统一头部结构与字段规范，用于自动生成 [SCRIPTS.md](SCRIPTS.md)。

## 必填/建议字段

请在脚本顶部包含以下字段（注释块中，保持原样）：

```
项目名称： <脚本名称>
项目作者： <作者>
下载地址： <App Store 或其他下载地址>
使用说明： <简短使用说明>
使用声明： <使用声明/免责声明>
```

说明：
- `项目名称`、`项目作者`、`使用说明` 会由工作流自动抽取并写入 [SCRIPTS.md](SCRIPTS.md)。
- 如未填写 `项目名称`，会退回使用文件名作为名称。

## 头部结构建议

建议脚本头部按以下顺序排列（示例结构）：

```javascript
/*
项目名称： ...
项目作者： ...
下载地址： ...
使用说明： ...
使用声明： ...

[rewrite_local]
...

[mitm]
...
*/
```

## 文件类型

[`../scripts/`](../scripts/) 支持以下扩展名参与自动索引：
- `.js`
- `.conf`
- `.snippet`

## 注意事项

- [SCRIPTS.md](SCRIPTS.md) 为工作流自动生成维护，请勿手动编辑。
